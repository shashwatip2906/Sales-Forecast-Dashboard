# Sales Forecast Analysis Dashboard — Tableau

## Project Overview

The **Sales Forecast Analysis Dashboard** is an interactive data visualization project developed using Tableau Desktop. It analyzes historical weekly sales data to identify sales patterns, compare store and department performance, evaluate holiday sales, and visualize potential future sales trends.

The dashboard combines key performance indicators (KPIs), comparative charts, and time-series forecasting into a unified view to support data-driven analysis.

## Project Objectives

- Analyze overall sales performance using key metrics.
- Compare sales across different stores and departments.
- Examine differences between holiday and non-holiday sales.
- Explore historical sales trends over time.
- Use Tableau's forecasting capabilities to visualize potential future sales trends.
- Build an interactive dashboard that makes sales insights easier to explore.

##  Dashboard Features

- **Total Sales:** Displays the aggregate weekly sales value across the dataset.
- **Average Weekly Sales:** Summarizes average sales per record at the weekly sales level.
- **Forecasted Sales:** Presents the forecast metric included in the dashboard.
- **Sales by Store:** Compares sales performance across stores.
- **Sales by Department:** Examines sales distribution and performance across departments.
- **Holiday Sales Analysis:** Compares sales associated with holiday and non-holiday periods.
- **Sales Forecast:** Visualizes historical sales trends alongside Tableau's forecast and forecast confidence intervals.
- **Interactive Filters:** Allows users to explore results by store and date range.

##  Tools & Technologies

- **Tableau Desktop** — Dashboard development, data visualization, and forecasting
- **CSV Dataset** — Source data for sales analysis
- **Data Analytics** — Aggregation, comparison, trend analysis, and forecasting

##  How to Explore the Project

1. Clone or download this repository.
2. Open the Tableau workbook (`.twbx` or `.twb`) in Tableau Desktop.
3. If prompted, reconnect the workbook to the source dataset.
4. Open the dashboard and interact with the store and date filters.
5. Explore the KPI cards, comparison charts, holiday analysis, and sales forecast.

**Note:** A packaged Tableau workbook (`.twbx`) is generally more convenient to share because it can include local data extracts and supporting assets. Check the workbook's data connections and ensure you are permitted to redistribute the dataset before uploading it.
